# GPINES Employee Training Manual - Project Memory

**Last Updated:** 2025-10-30

## Project Overview
Creating a comprehensive 16-hour Direct Care Staff Training Manual for Michigan Adult Foster Care (AFC) homes specializing in Alzheimer's/dementia care. Focus on REQUIRED pre-service training topics that new staff must complete before working with residents.

---

## Project Requirements

### Regulatory Compliance
- Must meet Michigan LARA requirements (Admin Code R 400.14204)
- 16 modules, each 1 hour of LEARNING time (not just reading)
- Michigan-specific for AFC Group Homes (6-bed, Golden Pines)
- Focus on Alzheimer's/dementia care (but applicable to all senior care)
- **EMPHASIS:** Pre-service REQUIRED training topics

### Key Principles
- **Self-study ready** - new hires can learn independently without instructor
- **Practical, not academic** - real-world applicable content
- **No fluff or redundancy** - substantive but not padded
- **Industry standard depth** - match existing professional training courses
- **All content must be cited** - verifiable sources for LARA compliance

---

## Deliverables Structure

### 1. STUDENT TRAINING MANUAL (Primary)
- 16 complete modules (core required training)
- Bonus modules for additional reference (e.g., First Aid knowledge base)
- Self-study ready
- Each module = 1 hour of learning
- Includes: learning objectives, content, case studies, scenarios, examples, reflection questions
- NO instructor notes in student manual

### 2. TEST BANK
- **3 variations per module** (Version A, B, C)
- 10 questions per version
- 30 questions total per module
- **480+ questions total** (16 modules × 30 questions + bonus modules)
- Answer keys for all versions with detailed explanations
- Allows rotation to prevent memorization

### 3. CERTIFICATE TEMPLATE (Future)
- 2-page format (like DCTC certificates)
- Shows individual module scores (percentage)
- Professional layout with signatures
- "Proof of Authenticity" design
- N/A for CEUs (DCW designation only)
- Must show all 16 module scores individually

### 4. INSTRUCTOR GUIDE (Optional/Future)
- Separate from student manual
- Facilitation tips for live training
- Optional - not required for learning

## Evidence-Based Care Models Integrated Throughout

1. **Tom Kitwood's Person-Centered Care**
   - Five psychological needs: Comfort, Attachment, Inclusion, Occupation, Identity (around Love)
   - Malignant social psychology to avoid
   - Positive person work

2. **Teepa Snow's Positive Approach to Care**
   - GEMS States Model
   - Hand-Under-Hand® technique (featured prominently in Module 02)
   - Positive Physical Approach

3. **Eden Alternative**
   - Three plagues: Loneliness, Helplessness, Boredom
   - Seven domains of well-being

4. **Validation Therapy (Naomi Feil)**
   - Enter person's reality
   - Validate feelings

5. **Montessori Methods for Dementia**
   - Focus on abilities not losses
   - Prepared environment

6. **Reminiscence Therapy**
   - Life story work
   - Memory triggers

## Module Content Standards (Per Module)

Each module includes:
- **Learning Objectives** (3-6 clear, measurable objectives)
- **Key Content** (comprehensive teaching material, 30-50 minutes reading)
- **Case Studies/Scenarios** (2-4 realistic examples specific to AFC settings)
- **Practical Examples** (Michigan-specific when applicable)
- **Reflection Questions** (for self-study engagement)
- **Key Takeaways/Summary** (10-15 essential points to remember)
- **References and Resources** (comprehensive citations for LARA compliance)
- **Total: Enough substantive content for 1 hour of LEARNING**

**Test Bank per module:**
- 3 versions (A, B, C) × 10 questions each = 30 questions total
- Answer keys with detailed explanations
- Passing score: 70% (7/10 correct)
