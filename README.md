## Project Overview

Comprehensive 16-hour Direct Care Staff Training Manual for Michigan Adult Foster Care (AFC) Group Homes. Designed for self-study by new hires, this manual covers all required pre-service training topics mandated by Michigan LARA (R 400.14204) with special emphasis on Alzheimer's and dementia care.

**Target Audience:** New direct care staff at Golden Pines AFC homes
**Facility Type:** AFC Group Home (6-bed capacity)
**Primary Population:** Seniors needing ADL assistance; majority with Alzheimer's/dementia
**Compliance:** Michigan LARA Adult Foster Care licensing requirements

## Key Features

### Michigan LARA Compliance
- Meets **R 400.14204** training requirements (7 core competency areas)
- Covers all required pre-service topics
- Michigan-specific regulations, procedures, and phone numbers
- All content cited with verifiable sources (defensible to LARA)

### Evidence-Based Care Models
- **Tom Kitwood's Person-Centered Care** (5 psychological needs)
- **Teepa Snow's Positive Approach to Care** (GEMS, Hand-Under-Hand technique)
- **Eden Alternative** (combating loneliness, helplessness, boredom)
- **Validation Therapy** (Naomi Feil)
- **Montessori Methods for Dementia**
- **Reminiscence Therapy**

### Self-Study Design
- Each module = 1 hour of learning time
- Clear learning objectives
- Practical, real-world content
- Case studies and scenarios
- Reflection questions
- Key takeaways
- No instructor required (though instructor guide available as supplement)

### Assessment Structure
- 3 test versions per module (prevents memorization)
- 10 questions per test (30 total per module)
- Passing score: 70% (7/10 correct)
- Detailed answer keys for learning

## Design Philosophy

**"Enable, Don't Disable"**
- Support resident independence
- Provide minimum necessary assistance
- Preserve dignity during intimate care
- Offer meaningful choices
- Focus on abilities, not just limitations

**Practical, Not Academic**
- Real-world applicable content
- Hands-on techniques
- Immediate implementation
- No theoretical fluff

**Person-Centered Care**
- Residents are individuals, not diagnoses
- Respect preferences and routines
- Maintain personhood despite cognitive decline
- Quality of life focus

## Usage

### For New Staff (Self-Study):
1. Complete modules in order (1-16)
2. Read student manual thoroughly (allow 1 hour per module for learning)
3. Complete assigned test version (A, B, or C)
4. Passing score: 70% (7/10 correct)
5. If failed: review module, retake alternate test version
6. Keep completed certificate for personnel file

### For Administrators:
1. Assign modules to new hires before working with residents
2. Rotate test versions (A, B, C) to prevent memorization
3. Grade tests using answer keys
4. Document scores on training certificate
5. File completed certificates in personnel records (retain 6+ years)
6. Schedule hands-on CPR/First Aid certification separately

### For Trainers (Optional):
1. Instructor Guide (future) will provide facilitation tips
2. Can be used for group training sessions
3. Supplement self-study with hands-on demonstrations
4. Use case studies for group discussion
