## Grading Guidelines for Instructors

### Scoring
- Each question = 1 point
- Total possible = 10 points
- Passing score = 7 points (70%)

### If Student Does Not Pass (Below 70%)
1. Review incorrect answers with the student
2. Identify knowledge gaps
3. Have student review relevant module sections
4. Allow retest with a different version (rotate A → B → C)
5. Document all attempts

### Documentation Requirements
Record the following information:
- Student name
- Test date
- Version administered (A, B, or C)
- Score (number correct / 10)
- Pass/Fail status
- Instructor signature
- If retaken: note original score and retest score

### Test Security
- Rotate versions to prevent memorization
- Do not allow students to keep tests
- Store answer keys securely
- Supervise test administration

## Common Wrong Answers and Teaching Points

### Misconception #1: "AFC homes provide nursing care"
**Correct:** AFC homes provide personal care and supervision, not 24-hour skilled nursing care. Residents needing skilled nursing belong in nursing homes.

### Misconception #2: "Task-centered care is more efficient, so it's better"
**Correct:** While task-centered care may seem efficient, it diminishes dignity and quality of life. Person-centered care improves outcomes and reduces behavioral challenges.

### Misconception #3: "DCWs can adjust medications if residents seem to need it"
**Correct:** DCWs cannot change medication dosages, diagnose conditions, or prescribe. This is outside their scope of practice.

### Misconception #4: "All residents should follow the same schedule"
**Correct:** Person-centered care means flexible, individualized schedules based on preferences, not rigid institutional routines.
